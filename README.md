# Handled HomeCare

Website for handledhomecare.com. Plain HTML/CSS/JS, hosted on Cloudflare Pages.

- Edit in VS Code with Claude Code, commit, and push to `main`. The site updates in about a minute.
- Preview locally: right-click `index.html` → Open with Live Server (VS Code extension), or run `python3 -m http.server` and open http://localhost:8000.
- Turn on online requests: paste a free Web3Forms key into `js/site-config.js`.
